DMS নিরাপদ ব্যাকআপ

সেটআপের চাবি তৈরি এবং ব্যাকআপ ফেরত খোলার টুল। এই ফাইল কোনো নেটওয়ার্ক সংযোগ করে না।

স্বয়ংক্রিয় ব্যাকআপ চালু হওয়ার আগে Worker আপডেট ও নিচের Secret সেটআপ করতে হবে। শুধু এই ফাইল খুললে ব্যাকআপ চালু হয় না।

১. একবারের সেটআপ

চাবি হারালে ব্যাকআপ খোলা যাবে না। চাবির ফাইল চ্যাটে, GitHub-এর Code-এ বা কোনো পাবলিক জায়গায় আপলোড করবেন না।
  1. Cloudflare → dms-attendance-login → Settings → Variables and Secrets। DMS_BACKUP_TOKEN নামের Secret যোগ করে token বসান।
  2. GitHub → visit-and-report → Settings → Secrets and variables → Actions → New repository secret। একই DMS_BACKUP_TOKEN যোগ করুন।
  3. GitHub-এর একই জায়গায় DMS_BACKUP_KEY নামের দ্বিতীয় Secret যোগ করে key বসান।
  4. প্রস্তুত DMS Worker v167 কোড Deploy করুন। আগের Firebase service-account Secret অক্ষত রাখুন।
  5. GitHub → Actions → DMS encrypted daily backup → Run workflow। সবুজ সফল ফল ও dms-encrypted-backups শাখায় নতুন ফাইল দেখলেই প্রথম ব্যাকআপ নিশ্চিত।
চাবি একবার সেট করলে অকারণে বদলাবেন না। পুরোনো চাবি দিয়ে পুরোনো ব্যাকআপ খুলতে হবে। প্রতিদিনের সময় আনুমানিক ভোর ৩:৩৭, বাংলাদেশ সময়। GitHub-এর দেরি, Firebase কোটা বা কোনো ব্যর্থতা হলে ওই দিনের ব্যাকআপ নাও হতে পারে।

২. ব্যাকআপ ফেরত খুলুন

GitHub-এর dms-encrypted-backups শাখা থেকে .dmsbackup ফাইল Download করুন। তারপর এখানে দিন।

এটি শুধু ফাইল খুলে দেয়; লাইভ Firebase-এ কোনো তথ্য লেখে না। Restore করার আগে বর্তমান ডেটার ব্যাকআপ রাখুন ও সঠিক তারিখ মিলিয়ে নিন। এই ব্যাকআপে Realtime Database-এর ডেটা ও Rules থাকে; Firebase Authentication-এর আলাদা user store বা Cloudflare Secrets থাকে না।
